# 🎮 Simon Says

A classic memory game built for the browser — watch the sequence, repeat it, and see how far you can go.

🔗 **[Play it live](https://vermillion-baklava-7e51db.netlify.app/)**

---

## How to Play

1. **Press any key** to start the game
2. **Watch** the flashing colour sequence carefully
3. **Repeat** the sequence by clicking the buttons in the same order
4. Each level adds one more step to the sequence
5. One wrong click and it's **Game Over** — how high can you score?

---

## Features

- 🟢 Classic four-button Simon Says gameplay
- 📈 Progressively harder sequences each level
- ⚡ Instant feedback on correct and incorrect input
- 🖱️ Simple click-to-play controls — no setup needed
